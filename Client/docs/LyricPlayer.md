# 猜歌歌词播放器（AMLL）

改动 `SongLyricPlayer`、`SongLyricScene`、`SongClipLyricSheet` 或任何 AMLL 渲染、测量、歌词动效时使用本文。歌词获取、清洗与切片见 [Server 歌词文档](../../Server/docs/SonGuessrLyrics.md)。具体 DOM 结构、字号、行高与组件参数以官方文档、已安装版本和代码为准，本文只记不能破坏的约束。

> **改动前必须先查官方文档 <https://amll.dev/>** 与已安装版本的类型声明、源码。组件内核是 `@applemusic-like-lyrics/core` 的原生 `LyricPlayer`，不使用 React wrapper；严禁凭印象推测其盒模型、布局计算或动画行为。

## 架构

- `SongLyricPlayer` 只负责 React 容器；`SongLyricScene` 用原生 Core 的**单实例**统一管理数据、媒体、测量和动画，不得同时用 React 绑定与命令式方法重复驱动同一状态。
- 歌词引用按完整内容深比较，覆盖逐字文本与时间、行级与逐字注音、翻译、和声及对唱标记；不得用只比文本与词数的摘要键。快照复制不得重建歌词节点。
- 翻译非空时屏蔽注音，无翻译时保留注音；测量必须计入所有可显示的副行。
- 手动出题的截取选择器复用同一歌词转换与原生 Core，但采用独立的静止布局：歌词行盒不随播放滚动、位移或缩放，只推进当前行的逐字遮罩。不能靠关闭 spring 实现静止，当前内核会在关闭 spring 时跳过逐字更新。
- 选择器的普通歌词回退按原始 `SongLyricLine.words` 判定，不把转换层的整行兜底词当作逐字能力；普通行不显示逐字遮罩。首次排版完成时可把初始选段滚进可见范围；此后播放与选段变化都不得主动改变选取列表的滚动位置。

## 测量与布局

- 自然高度唯一来源是原生歌词组的实测尺寸；用 `ResizeObserver` 持续监听歌词组、宿主、播放器与可见窗口，字体、宽度、字号变化必须重新计算。禁止按字数估算自然高度、轮询若干帧后永久锁定，或用人为延迟掩盖测量竞态。
- 手动片段可以长到整首，歌词组件的可见高度与行数解绑：宿主仍是自然高度，外面套一层受视口约束的窗口，上限只写在样式里，代码读窗口的实际高度。放得下时窗口贴合内容，表现与没有窗口一样。放不下时播放的对齐点落在窗口中心，总览在窗口内滚动；页面不跟着跳，也不把猜测栏顶出屏。
- 题目片段全量挂载，并覆盖内核的视口外占位行为；挂载不等于排版完成，不能把视口外的占位高度当真实行高。
- 歌词及全部子节点不接管指针事件，滚轮与触摸交给外层滚动容器；只关根节点不够，内核子容器可能重新开启内部滚动。内核把滚轮与触摸处理器挂在播放器根节点上且会阻止默认行为，只要有子节点接管指针（截取选择器的行），就必须在内核层关掉它的滚动。
- 播放器本体保持未缩放的自然高度，宿主高度为自然高度乘缩放比的向上取整；模式切换不得修改字体、行高、播放器高度或外壳高度。
- 初始化顺序：挂载歌词并触发布局 → 等字体就绪且内核实测尺寸一致 → 强制对齐并显示。禁止先显示从屏外飞入的临时位置；新曲不得沿用上一曲的测量或等待回调。

## 时间与更新

- `requestAnimationFrame` 同时驱动真实媒体时间与播放器更新，不触发 React 每帧渲染。
- 前奏使用实际媒体毫秒，不得把时间轴锁在首句；仅在未播放、暂停或音频时间严重异常时安全锚定首句。异常以片段起点为基准：手动片段可以早于首句任意远。
- 逐字遮罩是内核里自由运行的 Web Animation，启用后不再对齐媒体。只有媒体时钟真的在走（未暂停、未 seek、数据够播）才放行内核，走起来时按 seek 提交一次时间；`play` 事件不代表已经起播。
- 暂停和结束事件只暂停演出，不先倒回首句；只有完成状态切换才进入总览。
- 非播放状态仍保留内核的布局收敛更新；不得按固定时长强行停更新或访问私有弹簧队列。用有频率上限的定时唤醒加 RAF 绘制，恢复播放立即取消等待，无歌词不调度，卸载同时取消定时器与 RAF。
- 音频起播渐入、终点渐出由音频 Hook 处理，避免爆音与突然掐断。

## 总览与动画

- 总览必须保持**同一个播放器、同一批歌词节点**。切换时先读当前屏幕的变换，再计算目标布局，在同一次同步更新中以连续动画从旧位置移到新位置并缩放播放器；时长与曲线取 `Motion.ts`。裸调用布局计算会瞬移，只能用于隐藏中的首次落位或已捕获起点的连续动画。
- 快速重播从尚未结束的当前变换接续，总览被滚动过时把滚动量并进起点；动画结束清理填充状态与整体缩放；过渡途中不开放滚动，行盒位移不能变成滚动范围；减弱动效直接落位。卸载须释放播放器、媒体与字体监听、`ResizeObserver` 与动画帧。
- 歌词文字跟随现有主题前景色。总览的主行、副行、和声保持完整不透明度并去除逐字遮罩；遮罩切换要用可插值的数值透明度，不能直接移除遮罩导致未唱到的字瞬间全亮。明暗、模糊与遮罩的过渡只在进出总览时补间，结束即摘掉。
- 禁止为屏蔽第三方日志而改写全局 `console.log`；生产环境由依赖自身的构建条件移除调试日志。
