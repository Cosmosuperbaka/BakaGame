# 猜歌歌词播放器（AMLL）

改动 `SongLyricPlayer`、`SongLyricScene` 或任何 AMLL 渲染、测量、歌词动效时使用本文。歌词获取、清洗与切片见 [Server 歌词文档](../../Server/docs/SonGuessrLyrics.md)。

> **改动前必须先查官方文档 <https://amll.dev/>**（生命周期、进度对齐），并核对已安装版本的类型声明与源码。组件内核是 `@applemusic-like-lyrics/core` 的原生 `LyricPlayer`，不使用 React wrapper。其盒模型、`calcLayout`、`lyricGroupSize` 与 CSS 变量均以官方文档和已安装版本为准，严禁凭印象推测 DOM 结构或字号行高。

## 架构

- `SongLyricPlayer` 负责 React 容器，`SongLyricScene` 通过原生 Core 的**单实例**统一管理数据、媒体、测量和动画；不得同时用 React 绑定与命令式方法重复驱动同一状态。
- 歌词引用按完整内容深比较，必须覆盖逐字文本与时间、行级和逐字注音、翻译、和声及对唱标记。禁止只比文本与词数的摘要键（相同词数也可能有实际更新）。快照复制不得重建歌词节点。
- 翻译非空时屏蔽注音，无翻译时完整保留注音；测量时所有可显示的副行都要计入，不能只算翻译而漏算注音。
- 无歌词时保持紧凑提示。竞猜阶段纯音乐或无歌词时，标题更正为“音乐片段”，不误导玩家为房间关闭歌词显示。

## 测量与布局

- 题目片段全量挂载，并覆盖内核的 `content-visibility: auto` 为 `visible`。挂载不等于排版完成，不能把视口外的占位高度当真实行高。
- 高度唯一来源是原生歌词组的 `clientHeight`（与 AMLL 的 `lyricGroupSize` 同口径），用 `ResizeObserver` 持续监听歌词组、宿主与播放器；字体、宽度、字号变化必须重新计算。禁止按字数估算、固定最大高度、轮询若干帧后永久锁定，或用人为延迟掩盖测量竞态。
- 和声容器在播放/暂停/总览始终按真实尺寸占位（`position: relative`、零负间距、无几何变换），活动状态只改变明暗，否则播放时的测量不能复用于总览。
- 歌词及其全部子节点均不接管指针事件，滚轮和触摸交给页面滚动。仅给播放器根节点 `pointer-events: none` 不够，内核和声容器会重新开启内部滚动。
- 播放器本体始终保持未缩放的自然高度，宿主高度为自然高度乘缩放比的向上取整；模式切换不得修改字体、行高、播放器高度或外壳高度。
- 初始化顺序：挂载歌词并触发排版 → 等本段文字的 `document.fonts.ready` 与内核实测尺寸一致 → 强制对齐并显示。禁止先显示从屏外飞入的临时位置；新曲不得沿用上一曲的测量或等待回调。

## 时间与更新

- `requestAnimationFrame` 同时驱动真实媒体时间与 `player.update(delta)`，不触发 React 每帧渲染。
- 前奏必须使用实际媒体毫秒，**不得把时间轴锁在首句**，第一句歌词在前奏阶段保持未点亮；仅在未播放、暂停或音频时间严重异常时安全锚定在首句。
- 暂停和结束事件只暂停演出，不能先倒回首句；只有完成状态切换才进入总览。
- 非播放状态保留 AMLL 的动画更新（`pause()` 不代表布局弹簧已收敛）。内核没有公开的收敛判定，不能按固定时长停更新或访问私有弹簧队列；用有频率上限的定时唤醒加 RAF 绘制，恢复播放立即取消等待，无歌词不调度，卸载同时取消定时器与 RAF。
- 音频起播前一小段渐入、终点前渐出由 `useAudioClipPlayer` 处理，消除爆音和突然掐断。

## 总览与动画

- 总览必须保持**同一个播放器、同一批歌词节点**。切换时先读当前屏幕的变换，再计算目标布局，在同一次同步更新中以 Web Animations 从旧位置移到新位置并缩放播放器，两者共用 `Motion.ts` 的 `lyricOverview` 时长与曲线。裸调用 `calcLayout(true, true)` 会瞬移，只能用于隐藏中的首次落位或已捕获起点的连续动画。
- 快速重播必须从尚未结束的当前变换接续；动画结束取消填充状态并清除整体缩放；减弱动效直接落位。卸载须释放播放器、媒体监听、字体监听、`ResizeObserver` 与动画帧。
- 文字使用现有前景色和衬线字体（主行字重 500、副行 400），禁用深色叠加混合与文字辉光。总览的主行、副行、和声均为完整不透明度并去除逐字遮罩；遮罩不要直接换成 `mask-image: none`（无法插值，未唱到的字会在切换那一帧全亮，读作闪烁），改用经 `@property` 注册的数值透明度，并且明暗、模糊与遮罩的过渡只在进出总览那一段补间、结束即摘掉——播放中内核逐帧改这些值，常驻过渡会让逐字高亮落后于声音。
- 禁止为屏蔽第三方开发日志而改写全局 `console.log`；生产环境由依赖自身的构建条件移除调试日志。

## 验证

浏览器回归见 `Client/e2e` 下的歌词用例（真实 AMLL、字体、布局与动画中间帧）；jsdom 中的模拟高度不能证明真实排版正确。
