# CEE 客户端会话约束

修改猜猜呗（CEE）页面、房间界面或客户端会话行为时使用本文。玩法规则、协议、权限、隐私与搜索见 [Server/docs/CEE](../../Server/docs/CEE.md)；视觉原则见 [DesignGuide](DesignGuide.md)。界面布局、组件与文案以实现为准，本文不记录。

## 1. 会话与直链

- 断线保留房间画面与已输入的内容，顶栏给断线提示，与另两款同口径；重连后由房间运行时先订阅大厅、再带原凭据回座，展示态以回座确认的服务端全量整体替换，不在旧画面上续补丁。回座没成而房间还在（座位失效、临时失败）时让出房间，由房间页按直链入房重来；房间已不在则退回大厅。卸载释放连接、重试定时器与待请求，保留可恢复的标签页凭据。过期凭据须删除后允许重新加入。
- 主动离开先换页、房间页卸载时退房，与另两款同口径；退房一发出就让出本地房间，大厅不为它显示骨架，之后的入房与大厅订阅排在这次退房落定之后。没经房间页离开（浏览器后退等）而仍留着房间时，大厅挂载先兜底退房再订阅。
- 房间页直链加入被 `ROOM_NOT_FOUND` 拒绝时，用同一房号就地开一间增强房再进入（服务重启清空、测试房、已关闭房间的分享链接），与另外两款游戏同口径；密码错误、重名等其它业务拒绝原样报错。
- 直链进房全程自动加入，不弹“设置用户名”打断：先用本地已存用户名，没有就取访客名；私密房收到 `PASSWORD_REQUIRED` 才转入输入密码步。
- 进入房间期间不得抢跑状态同步，见服务端文档“协议、解析与会话”。耗时命令不设短超时，不报假失败。

## 2. 建房与设置

- 原版房的“大厅可见性”与增强房的“私密”是两种产品语义，界面措辞必须让玩家分清；具体文案与控件以实现为准。
- 反作弊房开关只对原生壳且已登录的建房者呈现；不达标时不呈现该入口，而不是点了才被拒。
- 反作弊房内开启窗口级防截屏，离开房间、换房或让出房间即恢复，断线保留画面期间照常开启，与排位系列赛同一口径；开启与关闭必须由和房间同时挂载的房间页发起，网页环境静默跳过。
- 非房主不得通过客户端推断或提升自己的设置权限；设置权限与只读语义由服务端按房主身份判定。反作弊房对所有人披露“这间房在记录”。
- 客户端不自行推断权限或过滤私有数据；服务端按连接视角裁剪，客户端只渲染收到的内容。

## 3. 排位页

- 排位页挂在 CEE 布局下，复用同一条 CEE 连接，不另建连接；排位状态只来自服务端推送的排位状态事件，页面不自行推断准入与阶段。未登录时引导登录；真正的准入以服务端拒绝为准。
- 网页端登录后只读查看：照常展示分数、战绩与排行榜，开始按钮置灰并就近说明对局要在客户端里打、给出下载入口。网页端不发状态请求、不订阅排位推送（状态请求要过客户端准入，网页发出只会被拒），只发资料、战绩与排行榜这类只读查询；连上过一次服务端即算就绪，之后断线与客户端同样保留只读展示。
- 主页的排位入口按服务端 `GET /api/site/config` 的 `ceeRankedEntry` 呈现：关掉时**置灰不可点并标注「暂时关闭」**，与「即将上线」同样是可见的不可用态，区别只在徽章文案；读不到按开放处理。开关只影响入口，排位页自身不另设可见性判断。
- 赛季显示以资料里的 `season` / `nextSeason` 为准：有进行中的赛季就在标题旁挂赛季徽章并写一行按北京时间读的截止日期（含当天），没有就把匹配与先打人机置灰并写一行原因（还没开始给开赛日期、已结束只说本赛季已结束），页面不自行按本地时间推断赛季。
- 排位的三条准入命令在壳内发出前先确认本次握手带了通道票据，没有就换票重连；被服务端以缺少通道证明拒绝时换票重试一次。
- 搜索框与角色图通过数据源上下文取数：缺省是多人房那套，排位页换成排位命令，组件本身不认识两种来源；图片缓存键按来源区分，避免同一角色在两种来源下的结果互相污染。排位数据源包住整个系列赛（对局、局间复盘与结算页），漏包的组件会落回多人房命令、向不存在的房间取图。
- 状态回包与事件流里的全量帧是同一份状态：请求途中事件流已经装过带修订号的基线时以事件流为准，回包只在事件丢失时兜底，否则修订号被清空、之后每个差量都要多拉一次全量。
- 排位首页的战绩可以完整翻看：面板内滚动，滚到底按游标往前翻页；翻页途中资料被刷新（刚结算完一场）时丢掉旧游标的那一页，不把两份分页拼错。排行榜进首页取一次（分数旁挂名次），切到排行榜标签再现取。
- 胜负、名次与分数变化优先用图标、胜负条与色块表达，并始终带文字或可访问名。人机局与真人局一样计分，没有每日计分额度，排队与对局里不再有「不计分」提示；结算写库失败的那一场才在结果页说明不计分。
- 断线时保留上一份排位状态只读展示，顶栏给与房间页同一句的断线提示，不退回连接中占位；同步基线随断线作废，重连后自动重取全量整体替换，期间到的差量不续在旧状态上。没连上时进入排位页不发注定失败的状态请求，等连上再取。
- 系列赛进行中开启窗口级防截屏，结束或离开即恢复，与反作弊房同一口径。
- 对手面板只画服务端给出的脱敏线索，不从任何其它字段拼回对手猜了谁；人机不显示分数。

## 4. 房间与结算

- 玩家栏、聊天与状态展示复用本项目公共组件；CEE 只提供自身业务字段，不复制另一款游戏的私有实现。
- 身份、次数、猜测进度与结算数据以服务端下发的字段为准；未知值显示为未知，不显示内部哨兵值，不靠颜色单独传达状态。
- 聊天与旁观的可见性、组队与出题人规则服从服务端 CEE 文档；客户端不做「收到但藏起来」的过滤。
