# 客户端工程约束

修改页面架构、房间接入、状态派生、自动保存、时间展示或前端遥测时查阅。跨端原则见 [Spec](../../Agents/Spec.md)；视觉与动效见 [DesignGuide](DesignGuide.md)。组件、常量、配置读代码（`Client/src/`），本文只记约束与理由。

## 1. 前端交付与一致性

- 页面按生产标准交付，包含真实流程、状态反馈、错误与响应式表现；不得把演示或占位页面作为完整实现交付。
- 修改页面前检查目标与相邻组件，复用项目现有控件和语义变量；基础控件（按钮、滑块等）不在业务组件里重写。
- 握手或异步列表首次返回前显示与真实卡片尺寸一致的骨架屏，不闪现假的“暂无房间”；保留 `role="status"` 与可访问的加载名称。

## 2. 组件分层

- 单文件失控膨胀要拆：组件文件变长时主动审视职责；“上帝组件”不并入主线。
- 音频调度、看门狗轮询、WebSocket 生命周期与会话重连封装为专用 Hook，不与视图 JSX 混杂。
- 多阶段房间拆成独立阶段组件，根页面只作容器：组装 Store 订阅、分发事件。
- 目录、命名、横向依赖规则见 [Spec §5](../../Agents/Spec.md)；全局基础 UI 不依赖业务 Store。
- **禁止用全局 DOM 事件传递业务信号**：阶段切换、倒计时超时、玩家动作由服务端推送或全局 Store 驱动，不用 `window.dispatchEvent` 横向绕过状态机。超时触发的自动提交基于 Store 里的阶段截止时间戳声明式响应，让组件随生命周期解绑。

## 3. React 渲染与 Effect

- 遵循“You Might Not Need an Effect”：不在 Effect 主体里同步 `setState`，级联状态改为基于 props/state 的纯计算派生；需要同步外部系统时才用 Effect，并有明确清理。不得为绕过 lint 把 `setState` 包进零延时计时器。
- 渲染流程中不读写 `ref.current`，保持渲染纯洁与可并发。
- 提交类按钮在请求发出至 ACK/失败前必须有 in-flight 禁用锁与加载反馈。

## 4. 协议基线与状态

- 状态同步引擎维护的快照基线必须严格等于服务端下发的公开数据模型：**禁止在协议快照上就地追加前端展示字段**（如向聊天数组 push 本地提示），否则 JSON Patch 的路径与索引错位。动画、淘汰展示与本地提示属于独立的展示派生层。
- 换房与退房时原子重置模块级版本追踪号、历史补丁缓存与基线引用，避免残留版本号阻断新房间同步。
- 聊天展示层按消息标识去重、按时间排序并保留有上限的条数（首次进入与重连全量也遵守）；不得裁剪原始基线。
- 组件不推断私有权限、不覆盖服务端快照；表单弹窗通过 Props 与校验回调采集数据，不隐式绑定具体游戏 Store。
- 谁是卧底的私有信息只来自私有状态，不从公共快照推断（规则见 [Server/docs/WhoIsFaker](../../Server/docs/WhoIsFaker.md)）。

## 5. 房间接入事务归属

- 页面直链、名称/密码补录与单人建房共用同一房间生命周期的 `AbortSignal`；仅换房或卸载取消，成功快照更新不能取消自身。
- 路由房号先按服务端规则归一（去首尾空白，测试房号大小写不敏感）再用于入房命令、会话键与快照房号比对。
- 入房请求期间的推送状态保留为事务暂存，不覆盖已确认房间的公开展示态；ACK 提交时一次安装匹配房间与令牌的状态。失败或取消不能混用旧房间命令身份与新房间快照。
- Store 在 ACK 提交身份与持久凭据前核验调用归属与连接代次；已取消的成功 ACK 用精确房间与令牌退房，释放落定后串行处理下一次入房，旧连接回包不得向新连接发送旧退房。
- 同房间、令牌与连接代次的恢复请求共享在途事务，允许 StrictMode 新 effect 接管；主动退房、房间关闭或席位替换也取消自动恢复归属。临时恢复失败保留令牌并拒绝，不伪报成功或自动创建；永久失败只清理对应会话并通知页面退出。

## 6. 自动保存与卸载

- 自动保存（配置、题目选项等非对局状态）只在等待阶段允许写入。回调里的 `enabled` 不能证明仍允许保存，**必须在实际发送边界读取 Store**：当前快照房间与草稿归属一致且仍处于等待阶段才提交。
- 组件卸载、离开视口或失焦刷新残余队列时，若对局已开始，必须立即丢弃待提交的草稿，禁止用旧表单快照覆盖进行中的服务端权威状态；合法的等待阶段防抖与卸载刷新保留。

## 7. 环境适应性

- 业务日期展示禁止无参 `toLocaleDateString()`，必须用 `Intl.DateTimeFormat` 显式锁定语言与基准时区；相对时间用原生 `Intl.RelativeTimeFormat`，抽到独立工具模块避免触发 Fast Refresh 规则；SSR/SSG 场景的相对时间节点标记 `suppressHydrationWarning`。
- 信封 id 与 Trace ID 不得假设存在 `crypto.randomUUID()`（HTTP 局域网等非安全上下文没有），必须提供符合 RFC 4122 v4 的降级生成，不得抛 `TypeError` 阻断对局。Trace ID 要含时间戳、单调计数器与随机熵。
- 根据环境变量拼接服务端地址时先剥离基准地址末尾斜杠，避免 `//api`。
- 接口基址的取值语义以 `Client/src/lib/ServerEndpoint.ts` 为准；生产不得使用同源相对路径（同源反代无法转发 WebSocket，`/api/*` 会被 SPA 兜底成 HTML），部署要求见 [Deployment](../../Agents/Deployment.md)。

## 8. 前端遥测

- 前端异常用 Sentry 全局托管（`ErrorBoundary` 与未处理异常）；上报统一经后端隧道。性能观测以 Spans 分布式追踪为唯一真相源，**禁止引入性能剖析插件**（缺少对应文档策略响应头时浏览器会拒绝并抛出不可消除的策略违规，且插件因此全局禁用）。
- 过滤良性中断：`ignoreErrors` 必须覆盖全部浏览器引擎的文案，不能只覆盖单一引擎。包含 View Transition 被打断，以及四种引擎各自的网络/模块加载失败文案；带锚点的短文案要用 `^` 锚定，避免裸串误伤无关文案。这类失败已有自愈重载兜底，不重复上报。
- **瞬时外部干扰必须自愈，且重载严格限流**：分块加载失败与第三方扩展改写 DOM 破坏 React 父子节点不变量，都应自动重载让玩家无感恢复。所有自动重载必须经统一的会话级一次性门闩放行（同一会话同一恢复点位只重载一次），浏览器禁用存储时安全拒绝并按原样抛出真实错误；禁止各处裸写 `sessionStorage` 判定。
- **协议层错误应答是数据，不是异常**：WebSocket 客户端收到的业务拒绝（房间不存在、密码错误、阶段不对等）与断连、超时同属正常协议应答，只记指标与日志；只有真正的 Error 才允许 `captureException`。判定走唯一的类型守卫，禁止各处重复实现形状探测。
- **模块脚本解析失败按栈帧剔除，禁止按文案猜测**：响应体不是合法 JS 时抛出的语法错误与 JSON 解析错误同形，`ignoreErrors` 无法精确表达，必须在 `beforeSend` 里仅当异常类型是语法错误**且**栈帧含内建模块解析帧时丢弃，不得按裸文案过滤。

## 9. 共享代码

共享源码的运行依赖由消费端显式声明，两端都必须声明 TypeBox；客户端的路径映射与 Vite/Vitest 去重把共享文件的 TypeBox 导入解析到 Client 安装，不依赖 Server 的依赖目录，也不复制 schema。映射位置见 [Conventions](../../Agents/Conventions.md)。
