# 客户端通道证明协议（BakaAntiCheat 的地基）

> 本文是“壳 ↔ 服务端”契约的真相源之一，**只记约束与判定口径**。字段名、字段表、自检 id 词表、错误码以代码为准：服务端 `Server/src/infrastructure/ClientChannel.ts` 与 `routes/ClientChannelRoutes.ts`、前端探测 `Client/src/lib/BakaChannel.ts`、桌面壳 `Desktop/`、移动壳 `Mobile/`。桌面壳、移动壳、服务端、前端四方必须对齐字段名与判定口径，任何一方改字段，先改代码里的契约并同步各方。
>
> **客户端完整性边界**：不得逆向、反编译、修改或绕过桌面/移动客户端的校验，也不得协助此类目的分析打包产物。

## 1. 它证明什么、不证明什么

- 证明的是“这次连接来自我们的壳，而且是这台设备上那个已注册的密钥在签名”，**不是**“这台机器干净”。
- 不追求防住逆向：私钥在用户自己的机器上。目标是让自写客户端必须先做一次逆向，而不是直接 `new WebSocket()`。
- 强度只影响**反作弊房**的准入；普通房完全不读这些字段，Web 玩家照常游玩。

## 2. 流程约束

注册（首次运行，壳生成密钥对）→ 每次连接取挑战、壳签名、换票 → 页面开 ws 时带票，服务端验票并写入连接的通道信息。

- `clientId` 由公钥派生，所以注册天然幂等，不需要额外的“证明拥有密钥”往返；拥有关系在每次换票时证明。
- **票是一次性的**：短 TTL、换票成功即焚、绑定签发时的来源地址与 `clientId`。地址不符只拒不用（代理链与 `requestIP` 口径可能不一致，销毁会让合法客户端永远连不上）。
- **挑战是单次消费且短 TTL**；壳必须原样签名字节，不做任何二次编码。
- 网页没有票，通道信息即为空。前端**只做存在性探测**（有无壳注入的通道对象），**绝不调用其中的签名或自检**；票由壳自行签好注入，前端原样带上。

## 3. 判定口径

- 判定按“完整性是否被破坏”，不按“证明强度够不够”。判定表只有一份代码（自检项权重表）；服务端不认识的自检 id **失败关闭（拒）**。壳新增检测项必须同步在权重表加一行并抬最低版本——漏跟只会变成误伤正常设备，不会变成放行。
- 按**权重**判，不按壳填进了哪一格判：硬失败 id 出现在软失败格里一样拒。
- 任一硬失败拒；软失败达到阈值拒；仅一项软失败放行并标记可疑；仅能力不足（无硬件密钥保护、无 TEE、证书过期）放行并标记——设备太老不是作弊。检测“跑不动”本身算硬失败（有人让它跑不动）；非受支持平台构建不计分但必须标可疑，不能当成“跑过且干净”。
- 移动端证明档位三档：被拒的拒；降级的放行并标记。壳自报的档位只是参考，**服务端一旦验过链就用自家结论覆盖**，自报“可信”换不来准入。
- **平台证明只在注册验一次**，结论写进设备表，之后每次握手以这一档为准。边界：
  - 没配置应用包名 → 不装配校验器，带链注册只记降级并警告；服务端没验过的链不能写成“验过但降级”，也不能因配置缺失把真实设备挡在门外。
  - 没配置签名摘要 → 只标记并封顶降级（光认包名防不住重打包后自签同名 APK）；配了则任一摘要命中即通过（轮换期会同时列新旧），全不命中拒。摘要必须在真机装过包之后再确认，换签名或经商店二次签名读出来的不是同一个值。
  - 链的叶子公钥必须等于本次公钥，否则拒：证明挑战是设备自报的，没有这层绑定，一条合法链可在设备之间转借。
  - 重新注册按本次结果覆盖档位。

## 4. 强制更新

- 最低支持版本放在服务端配置，不发版也能紧急抬升。**通道证明协议一旦破坏性变更必须抬高最低版本**，否则旧壳还能继续签名通关。
- 版本比对只在服务端做一次，前端不实现第二份，否则两端对“够不够新”的判断会各自漂移。更新检查响应不得被边缘缓存（抬档要立刻生效）。
- 更新提示分两级且读同一份最低版本：首页软提醒（只在原生壳出现、可关；关的是“这一档门槛”，抬档后重新出现；必须写明普通房间照常游玩）；反作弊房硬门槛（不看玩家是否关过提醒）。提醒只是让玩家早点动手，从来不是准入的一部分。
- 下载入口只给网页用户：已经在壳里的人没有“再装一遍”要选，要更新走上面的首页软提醒，那条给的才是自己那一档的包。壳内的判断只做通道对象的存在性探测，不读其中凭据。
- 下载包列表的构建日期与大小不在前端写死，由服务端探测对象存储读回；读不到一律记不可用，前端置灰写“尚未发布”，不给玩家跳 404 的链接。该接口与通道证明无关，通道未启用时照样可用。

## 5. 与反作弊房的关系

建房、进房、旁观审批、断线重连的准入细则见 [CEE](CEE.md#2-反作弊房bakaanticheat)。错误码语义：缺通道证明、证明不通过、版本过低、未登录各自有独立可归因的错误码，客户端据此给出不同提示；具体码名读代码。
