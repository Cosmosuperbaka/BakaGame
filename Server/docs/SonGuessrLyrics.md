# 猜歌歌词获取、清洗与出题切片

修改歌词获取、清洗或出题切片时使用本文；播放器与排版见 [Client 歌词播放器](../../Client/docs/LyricPlayer.md)；仅改登录、搜索或房间逻辑不需要读。词表条目、正则、阈值以代码与测试为准；清洗判定器的误杀/漏网教训见本机 `.agent-notes/pitfalls-lyrics.md`（不入库）。

## 歌词获取

按优先级回退，前一级有有效结果就停止：

1. 网易云官方逐字歌词。命中时不请求任何第三方服务。
2. AMLL 官方 TTML 歌词库，按网易云音乐 ID 匹配。
3. AMLL 歌词库按歌曲名（与歌手名）搜索匹配。
4. 网易云普通行级歌词。
5. 都为空则 `lyrics = []`，展示“纯音乐或无歌词”，并随机截取音频片段出题。

约束：

- 第三方回源必须有短超时、LRU 缓存与独立有界队列；搜索和下载共享截止预算，同键合并请求。网络超时、服务端错误等瞬态失败不能写入长期缺失缓存。
- 歌词缓存只存歌词本身，切片每次出题重新随机选取。

## 出题切片

- 窗口必须有演唱连续性：相邻两句间隔不得超过长间奏阈值，严禁把跨越超长间奏的两段唱词拼成一个窗口；单句跨度过长的候选跳过。
- **窗口必须能收缩**：设定行数下找不到可行窗口时，从设定行数逐行收缩（有下限），只有连最小窗口都不存在时才退回纯音频窗口；不能因为单行跨度过长就把整首歌的歌词丢掉。保留空歌词与单行歌词判为不可出题的既有语义。
- 和声歌词（`isBG`）不能作为题目开头，也不能充抵题目行数；落在出题区间内的和声歌词完整保留在片段里，供播放时作背景演出。
- 音频选区终点适当后延；起点提前量不得越过上一句的结束时间（上一句还在唱就起播会两句叠音）；上一句没有可信结束时间戳时取固定提前量。渐入渐出由客户端处理。
- 逐字行的 `endTime` 必须保留原值，不得被下一行起始时间覆盖；仅无逐字信息的行级歌词才用下一行起始时间或兜底时长补算。
- 歌词行数不足（纯音乐或未上传歌词）时，改为在歌曲时长内随机截取与设定行数成比例的音频片段。
- 出题侧必须用同一套单行判定二次校验，防止缓存里的历史脏数据被截取。

## 手动出题片段

- 手动出题的片段由出题人在客户端选定，服务端只做边界校验：长度不少于 5 秒、起止有序、终点不越过歌曲时长（时长未知时不做上界校验）；最长就是整首。
- 预览时服务端按房间设置随机抽出一段建议区间下发，客户端默认选它；直接确认时播放的就是这一段。
- 越界或参数不成立时**不报错**，回退到原来的自动随机切片（与没传片段完全一致），不退回整曲。自动抽题流程不经过手动校验。
- 客户端必须把无效区间挡在提交之前；服务端回退只作为异常输入的最后兜底。
- 客户端预览只能由当前待出题人获取，返回音频地址、行级歌词（不含逐字数据）与建议区间；猜歌阶段的玩家不得拿到答案的试听与歌词。
- 片段随回合写进房间快照，重启恢复沿用同一段；展示仍受房间的「显示歌词」开关约束。

## 歌词清洗

进入游戏前必须：解析多时间戳 LRC 并重算结束时间；删除署名、版权、占位等非歌词行；保持时间轴连续。

核心约束：

- **署名判定必须分层，禁止退回“穷举词表 + 行首分隔符”。** 顺序：剥离行首装饰与包裹括号 → 词表快速路径 → 结构判定兜底 → 连排署名块整体剔除。词表不必追上同人圈新标签。
- **非署名类无效行各有独立判定**，且都必须接入 `isUnusableLyricLine`（否则出题侧二次校验不生效）：版权与法律声明、对唱角色标注、注音符号行、带后缀的纯音乐占位、占位遮罩行、整行括号包裹的舞台指示（保守判定）、无分隔符的英文署名、复合限定标签。
- **反误杀（最重要）**：
  - 严禁子串包含误杀；只删整行与歌手/专辑名、“歌名+歌手”连写完全匹配的元数据标题行。单独唱到歌名的整行是真歌词。
  - 严禁全局副歌去重，必须在整曲时间轴上保留所有重复演唱。
  - 单个中日文字符是合法歌词；纯人名串判定要求至少两段短片段；角色词单独成标签时区分“空标注”和“标记 + 歌词”（后者是真歌词）。
  - 新增任何规则必须同时跑“含该字词的正常歌词”反例。
- **判定与解析只提供纯文本**：两个音乐 provider 共用同一套歌词行判定与 TTML 解析，它们不认任何上游响应形状；解析器需要的 `globalThis.DOMParser` 由提供解析的那个模块自己补齐，不能靠「先 import 某个具体 adapter」这种副作用生效。
- 回归以仓库内可复现的测试为准：每条受影响路径至少覆盖一条应删除与一条应保留的代表样本。新形态先验证再沉淀正式用例；不把个人本地脚本设为交付前置条件。
- 抽样验证仅在任务需要且有真实接口授权时进行，按问题选择样本与有限批次，达到相关回归标准即停。验收标准是“剔除的全是署名/占位/舞台指示，且没有一行歌词被剔除”，不是剔除数变多。
