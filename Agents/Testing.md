选择验证范围、编写测试或修改 CI 时查阅。命令、脚本名、端口、阈值、测试文件清单一律读各包 `package.json`、`.github/workflows/` 与测试目录，本文只记约束与理由。

## 验证范围

| 改动类型 | 完成所需的验证 |
|---|---|
| 纯文档或注释 | 检查 diff、链接与引用路径、规则一致性；运行 `node scripts/CheckDocs.mjs`；不运行无关业务套件 |
| 局部服务端行为 | 相关服务端测试 + 类型检查 + lint；新增行为或缺陷补有判别力的回归 |
| 局部客户端逻辑 | 相关客户端测试 + lint + 构建 |
| 页面样式或动效 | lint、构建与受影响页面的浏览器验证；按 [DesignGuide](../Client/docs/DesignGuide.md) 检查相关状态与视口，不为样式类新增镜像单测；受影响组件的故事同步更新，并做改前改后截图对照 |
| Storybook 故事、假数据或截图工具 | 应用类型检查、lint、故事静态构建，相关故事截图零失败、零控制台错误 |
| 共享协议、跨游戏基础设施、全局状态同步 | 两端类型/构建与相关协议、Store、服务回归；涉及握手或路由时验证真实命令 ACK |
| HTTP 路由或接口契约 | 两端类型检查与相关协议回归；重新导出 OpenAPI 产物并提交。契约面由 OpenAPI 测试打真实路由核对，产物与代码不同步时在库比对报红 |
| 快照、私有状态、封包或广播频率 | 网络容量测试，保留全部容量与最终同步断言 |
| 歌词几何、字体或动画 | 歌词浏览器回归；jsdom 高度模拟不替代真实浏览器 |
| 资源、构建插件或静态外壳 | 资源冒烟与相关 SEO / 资源 E2E |
| 依赖或运行时升级 | 升级前后以同一组检查验证受影响包；浏览器/构建依赖另跑相关 E2E，基础运行时或跨端影响覆盖两端 |
| 格式化或文件改名 | 格式校验 + 两端 lint；改名同时核对静态分析入口配置、文档路径引用与文档检查 |
| CI、发布准备或明确要求完整回归 | 对应包完整验证链；发布另查 [Deployment](Deployment.md)；服务启动/运维端点改动补生产冒烟 |

本地单测和隔离冒烟可直接运行、修复本次引入的失败并重跑。通过后不重复扩大检查；新改动、失败或未消除风险才增加验证。全量 CI 门禁继续执行，不要求每个局部编辑都先跑完整 CI。

普通测试使用隔离夹具与 Mock 上游。真实第三方（如网易云）测试单独调用、会用到本地凭据，按已有授权与 [NeteaseMusicApi](../Server/docs/NeteaseMusicApi.md) 执行，不当作普通单测。环境缺失时记录未验证范围，不用降低阈值或伪造通过来交付。

## 静态检查与格式化

- 两端使用同一套规则面：推荐规则集 + 认知复杂度上限 + 一组缺陷类的类型感知规则（浮动 Promise、误用 Promise、对非 thenable 的 await、对象转字符串、抛非 Error、非 Error 的 reject、未绑定方法）。具体规则与阈值读 `eslint.config.*`。
- **类型感知的工程指向要显式**：Client 的类型感知只对 `src/**` 开启，且必须显式指向应用 tsconfig（根 tsconfig 是 references 壳，项目服务会撞上它而报文件找不到）；Server 用项目服务覆盖源码、脚本与测试。不在工程内的文件（E2E、构建配置、集成脚本）只走语法级检查。
- **lint 与类型检查是两条 TypeScript 线**（见 [Conventions](Conventions.md)）：规则崩溃只在 lint 出现，lib 类型收紧只在类型检查出现。动 TypeScript 依赖或 override 后两端都要重跑。
- 新增违规直接失败；存量违规的处理方式以仓库当前 lint 配置为准，**不新增内联禁用来掩盖问题**，只有刻意的设计才允许就地 `eslint-disable-next-line`，且必须写明理由。改规则、阈值或覆盖范围时同批重跑两端 lint，并确认静态分析仍零问题（新增的 lint 依赖必须被配置直接导入）。
- 格式化器是根级 Prettier，改格式只用它的 write / check 入口；忽略范围读 `.prettierignore`。`endOfLine` 的 `auto` 不许改（原因见 Conventions）。格式化改动单独提交（`style(Core)`），不与业务改动混提；全仓重排的提交记进 `.git-blame-ignore-revs`。
- 静态分析（knip）检查未使用的文件、依赖、导出与类型；入口（测试、故事、E2E、preload 夹具）在配置里显式声明，不用忽略清单掩盖真实问题。Knip 加载 Vite 配置时只读不写盘（生成目录重建在插件钩子里完成）。
- 文件名由 lint 规则强制（见 Conventions §1.2）。

## 门禁

- **验证矩阵只在本文维护**：专项文档只写“验收要点”，不复制命令、测试文件名或逐用例清单。
- 服务测试不连接真实数据库：仓储为可选注入，未注入即不落库（见 [Database](../Server/docs/Database.md)）。
- 客户端生产构建后执行资源冒烟（入口 HTML、固定资源、哈希资源、SPA 路由、MIME）。
- 两端覆盖率命令必须留在 CI，阈值只在各自脚本/配置里维护，文档不复制数值；CI 保留 lcov/HTML 报告。覆盖率是查缺与阻止回退的工具，不是堆低价值断言的理由；阈值修改要说明基线、空白和风险。**LCOV 的函数/行计数按单值解析，不能套用逐行双值格式；无有效计数的报告必须失败。**
- 生产服务冒烟启动真实服务进程，检查探针与三款游戏 WebSocket 的大厅订阅 ACK；使用隔离端口和无网络上游，不访问真实第三方。
- 客户端 CI 在生产构建后构建 Storybook，防止故事与截图工具随组件失效。
- 文档门禁 `node scripts/CheckDocs.mjs` 无条件执行：相对链接与锚点、文档导航登记、冻结文档校验（见根 `AGENTS.md`）。纯文档改动同样受约束。
- 聊天气泡等关键元素使用稳定的 `data-testid`，E2E 不读取样式类名；关键落地页和聊天流程把页面异常、控制台错误与非预期 4xx 转为测试失败。
- **尚未纳入门禁、不得按已覆盖对待**：拆分过大的 E2E 文件、长连接稳定性与断线矩阵、夜间真实第三方集成、持续容量趋势报告、按模块设置的细粒度覆盖率阈值。新增测试先补齐行为和夹具，再考虑纳入 CI。

## 测试分层

| 层级 | 运行器 | 主要职责 |
|---|---|---|
| 后端单元 | `bun:test` | 纯规则、连接筛选、错误码、广播隔离、Provider 本地数据与远端回退、请求截止/排队 |
| 后端服务回归 | `bun:test` | 三款游戏的状态机、会话重连、权限、房间生命周期与互通回合 |
| 协议与传输集成 | `bun:test` | 消息解析、OpenAPI、HTTP、CORS、真实 WebSocket、命令分发、上游接口 Mock |
| 账号与鉴权、对局记录 | `bun:test` | 见 [Account](../Server/docs/Account.md)、[GameRecord](../Server/docs/GameRecord.md) 的验收要点 |
| 网络承载回归 | `bun:test` | 容量预算、差量与全量同步 |
| 前端单元与集成 | Vitest + jsdom / Testing Library | 会话存储、解析、WebSocket 客户端、Hook、Zustand 与 WS 联动、路由 |
| 端到端 | Playwright | 落地页、大厅、移动端、多浏览器真实房间流程 |
| 组件截图 | Storybook + Playwright | 全部组件与阶段状态的亮/暗、多档视口范例，供样式审查与改前改后对照；不做像素断言 |

## E2E 隔离

- 常规浏览器回归先用隔离构建脚本构建再运行；构建禁止加载 `.env`，显式清空遥测 DSN、指向本地后端，mode 仍为 production（不绕过仅生产生效的行为）。静态预览同样不加载项目配置与代理，只服务 production dist，显式绑定 `127.0.0.1`，不碰用户已有的 `localhost`/`::1` 服务。`playwright test` 不会重建 dist，手工运行前也必须走隔离构建。
- E2E 统一导入隔离夹具：默认 context 自动装守卫，额外参与者使用夹具提供的隔离 context，**不裸调 `browser.newContext`**。创建页面前安装 HTTP/WS 路由，仅允许回环地址，外部连接 abort/close 并在 teardown 明确失败；禁用 Service Worker；允许的 HTTP 请求取回再 fulfill，带重定向的响应明确失败，不让浏览器在只拦首跳的机制下隐式外跳。
- 页级合成夹具不得用 `route.continue()` 绕过 context 守卫，未命中用 `fallback()`。可选外部图片只能本地合成 fulfill，WS 图片夹具只匹配回环。原有页面异常、控制台、非预期 HTTP 错误断言保留。第三方登录二维码这类外部依赖只替换其创建/轮询 ACK，使用不可扫描的合成图片，其余房间命令透传真实隔离服务；**不以开放真实出口让登录测试通过**。
- 隔离 context 通过统一的关闭函数收尾：保持页级拒绝出口，用框架的 `unrouteAll({ behavior: "wait" })` 排空在途 handler，最后关闭目标；不用 `ignoreErrors` 吞异常，不在 fulfill 后再 abort。
- `APIRequestContext` 不受浏览器路由拦截，新增 API 请求必须沿用显式的回环校验与禁用自动重定向，不得直接请求外部 URL。
- Local Network Access 权限只授予当前套件回环 origin，不禁用浏览器安全，也不授权外部来源。
- 服务端用隔离启动脚本（禁用 `.env`），不复用真实服务。歌词独立套件按其专项入口执行，探针请求真实生产 CSS 而不是夹具 HTML，冷编译完成后才启动首例；**不靠扩大超时或跳过加载检查掩盖资源未就绪**。

## 测试编写与维护

- 新行为和缺陷修复覆盖用户可观察结果，缺陷用例应能在修复前失败；纯文案、格式与无行为变化的低风险修改不为覆盖率添加无意义测试。
- 状态机从公开服务入口测试，非 IO 纯业务逻辑真实运行。Zustand 用 `store.setState` 预置并重置状态，不整体 Mock 核心 Store，也不在 Mock 中重写系统。
- UI 断言绑定 ARIA 角色、标签、可见文本与数据契约；`data-testid` 只用于稳定业务元素。布局断言检查 Landmark、导航、真实几何和溢出，不绑定样式类名、整串 class 或 DOM 深度。
- 长连接与 Store 测试用语义门面（如 `emitStatus`、`emitMessage`）分发事件，不裸调监听器数组下标。
- 时间、退避、抖动、随机与网络驱动通过 `now`、`random`、`fetcher` 参数注入，使用虚拟时钟与受控 Promise；Provider 测试不做真实 sleep，不用全局 fetch / 随机替换污染并发用例。
- 浏览器用例不拿固定 sleep 冒充竞态：要「中间态」就读实测状态（如祖先链累乘后的 `getComputedStyle` 不透明度）确认它存在，读到才动作、读不到显式失败。窗口比采样往返还短时，从创建时拉长那一条动画的时长（缓动与状态序列不变），别赌机器快慢。
- 失败断言核对业务错误码、HTTP 状态或关键错误描述；不使用裸 `toThrow()`、裸 truthy 或只检查调用次数的假测试。安全防护变更另遵循 [Spec §7](Spec.md)。
- 每例独立房间、连接、目录和数据，不依赖顺序；清理前排空持久化写队列。多浏览器上下文、Worker、端口、WebSocket 与子进程在 `finally` / `afterEach` 释放，超时终止子进程。
- 名称描述行为；不提交 `.only`、无理由 `.skip`、重命名后的镜像测试或已删除模块的 Mock。
- 新增生产资源在构建后通过 preview 验证 HTTP 200、MIME、非空内容与可解码性；只测插件函数或 Vite 开发模式不够。
- E2E 关注跨页面、跨进程和真实用户风险；未处理 rejection、`pageerror`、console error 或非预期 4xx/5xx 令用例失败，预期错误用带原因的明确白名单。
- 生产服务冒烟保持隔离、可重复且不访问第三方；真实第三方集成单独运行、输出脱敏，不进常规 CI。需要数据实体的真实角色 E2E 按 `Server/data/README.md` 获取数据。

## 领域专项验收

- **CEE 网络容量**：使用真实原生服务与生产状态编码器，包含公共/私有两通道的全量校准，连同请求、ACK、帧开销与余量不超预算；必须断言实际产生了补丁，不能只检查事件登记或跳过未变化的校准流量。
- **CEE 图片提示**：用生成的栅格图经过真实解码、缩放、模糊与编码，校验像素尺寸和模糊后方差下降；下载失败、无效地址、损坏图片统一返回业务错误，流式超限及时取消，失败不留在成功缓存也不阻塞后续同键请求；不访问真实上游。
- **歌词几何与动效**：独立启动 Vite（独立依赖缓存，不运行应用资源预处理、不写生成目录与 dist），真实挂载 AMLL 与生产 CSS，只替代媒体解码与房间传输；测试入口只在 `e2e/fixtures/`，不进生产构建。必须检查首末行边界、字号与宽度变化、首次可见帧、完成与重播的中间帧；不得以手工估算高度的 jsdom 断言代替浏览器验证。

## 组件截图

用于样式审查与改前改后对照，不做像素断言，也不替代 E2E 与单测。

- 故事与组件同目录，标题按基础控件 / 公共组件 / 页面 / 各游戏分组，故事名写中文状态。假数据放故事夹具目录，按共享类型构造且与真实业务口径一致；文案遵守 [DesignGuide](../Client/docs/DesignGuide.md)。
- 连 Store 的组件在 `beforeEach` 用预置工具设置状态，预览层在每个故事前复位全部 Store。故事不得渲染 `layouts/`、`contexts/` 或调用 WS 初始化，不访问外网：图片用本地资源或数据 URL，截止时间在运行时计算。
- 截图范围由故事 tags 决定（整页多视口、含 Portal 的整页、仅手机、不拍、按根元素取景），每种都出亮、暗两套；暗色只用于样式检查，站内不开放。
- 截图脚本自启独立端口的 Storybook，关闭过渡并模拟减弱动效，等字体、图片与动画落定再拍；故事渲染失败、页面异常或控制台错误令命令非零退出。`--filter` 只重拍匹配的故事，`--out` 另存一份供对照。
- 截图基本可复现（固定“当前时间”，动图换首帧，同步解码），但仍会有边缘像素级抖动，改前改后对照要按容差比较或目视，不能只比文件哈希。新增故事若两次截图差异明显，先排查随机数、真实时间或外部资源。
- Storybook 与应用 dev/build 都会重建生成目录，不要与其它 Vite 进程并行启动。

## 排障

### E2E 本地假红

`test:e2e` 报 webServer 等待超时，而手动访问就绪地址正常时，先核对代理环境：会话里存在 `HTTP_PROXY` / `HTTPS_PROXY` 时，Playwright 的就绪探测会走代理而拿到 502/404，Node `fetch` 默认不读代理变量，因此手动探针会给出误导性的“一切正常”；后端日志里反复出现对根路径的 404 即这些被转发的探测请求，不是页面请求。仅在确认代理误路由后，在当前测试子进程内移除代理变量（含小写形式），测试结束恢复，不更改用户全局网络配置；保持预览对 `127.0.0.1` 的硬绑定。逐次打印探测 URL 与状态码用 `DEBUG=pw:webserver`。不代表所有超时都由代理造成。

### Worker 异步错误断言

对已初始化 Worker 的异步错误回包，**不得直接 `expect(promise).rejects`**（会阻塞消息分发）。先用原生 Promise 捕获结果，再同步断言明确的业务错误码；禁止延长超时掩盖挂起。该写法不随 Bun 版本升级失效，要移除必须先单独验证不再挂起。
